# Cranky Cats 🐱

An original, browser-based, landscape 2D slingshot physics game prototype. Built for touchscreens and mouse using Phaser 3 and Matter.js.

## Version 0.1: Furball vs. the Rats

- Pull Furball (orange Scottish Fold) backward and release to launch him.
- Tap again while he's flying to launch an explosive hairball.
- Knock down a stack of wooden and stone blocks and pop three rats.
- Four cats per attempt; each rat earns 5,000 points and unused cats earn 10,000 each after a win.
- Restart from the lower-left button.

## Play

Once GitHub Pages is enabled, visit: https://magicalboyco.github.io/cranky-cats/

To enable Pages: GitHub repository **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. It can take a moment for GitHub to publish the page. The prototype requires internet access to load Phaser from a CDN.

## Current status

This is the first interactive prototype, not finished production art. The cats and rats are drawn procedurally as placeholders; gameplay and physics must be tested in Safari and tuned. The other five cat characters and additional levels will be developed later.

## Character plan

- **Furball** — orange Scottish Fold — drops a hairball
- **Poppy** — pink calico cat — splits into three kittens
- **Boom Boom** — purple Korat — explosive shockwave
- **Zippy** — blue Persian — fast dash
- **Pickles** — green American Shorthair — boomerang
- **Mochi** — yellow Maine Coon — heavy smash

No Rovio character art, branding, sound, or levels are used.
